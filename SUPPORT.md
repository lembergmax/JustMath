# Getting help

- A question about how to use JustMath: start a [discussion](https://github.com/lembergmax/JustMath/discussions).
- A bug or a wrong result: open an [issue](https://github.com/lembergmax/JustMath/issues/new/choose) with the version, the input and what you expected.
- A security problem: follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- Documentation: the [README](README.md) covers usage, and the API documentation for every release is on [javadoc.io](https://javadoc.io/doc/io.github.lembergmax/justmath).
